🔧 数据库初始化指南

欢迎使用奥领数控品控系统！按照以下步骤完成数据库初始化，即可开始使用系统。

⚠️ 重要提示

如果您之前已经执行过数据库初始化，请跳过此步骤。如果不确定，可以继续执行，SQL 脚本会自动跳过已存在的表。

1 登录 Supabase

打开浏览器，访问 Supabase 官网并登录您的账户：

在 Dashboard 中，找到并点击您的项目：qc-system

在项目左侧菜单中，找到并点击 SQL Editor 图标（通常是一个代码图标）

或者直接访问：SQL Editor

4 复制 SQL 脚本

点击下方按钮复制完整的数据库初始化 SQL 脚本：

-- ======================================== -- 奥领数控品控系统 - 数据库初始化脚本 -- ======================================== -- 1. 创建设备表 CREATE TABLE IF NOT EXISTS devices ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, device_number TEXT UNIQUE NOT NULL, model TEXT NOT NULL, customer TEXT NOT NULL, order_number TEXT NOT NULL, status TEXT DEFAULT 'assembling', created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(), updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 2. 创建组装检测表 CREATE TABLE IF NOT EXISTS assembly_checks ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, device_id BIGINT REFERENCES devices(id) ON DELETE CASCADE, check_item TEXT NOT NULL, description TEXT, photo_path TEXT, inspector TEXT, status TEXT DEFAULT 'pending', created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 3. 创建测试报告表 CREATE TABLE IF NOT EXISTS test_reports ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, device_id BIGINT REFERENCES devices(id) ON DELETE CASCADE, test_item TEXT NOT NULL, standard TEXT, result TEXT, tester TEXT, test_date TIMESTAMP WITH TIME ZONE DEFAULT NOW(), confirmed BOOLEAN DEFAULT FALSE ); -- 4. 创建发货清点表 CREATE TABLE IF NOT EXISTS shipping_checks ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, device_id BIGINT REFERENCES devices(id) ON DELETE CASCADE, item_name TEXT NOT NULL, item_type TEXT, required_quantity INTEGER, actual_quantity INTEGER, checker TEXT, status TEXT DEFAULT 'pending', created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 5. 创建客户反馈表 CREATE TABLE IF NOT EXISTS customer_feedback ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, device_id BIGINT REFERENCES devices(id) ON DELETE CASCADE, feedback_type TEXT, description TEXT, rating INTEGER, customer TEXT, created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 6. 创建改进建议表 CREATE TABLE IF NOT EXISTS improvement_suggestions ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, device_id BIGINT REFERENCES devices(id) ON DELETE CASCADE, suggestion TEXT, priority TEXT, status TEXT DEFAULT 'pending', created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- ======================================== -- 启用行级安全策略 -- ======================================== ALTER TABLE devices ENABLE ROW LEVEL SECURITY; ALTER TABLE assembly_checks ENABLE ROW LEVEL SECURITY; ALTER TABLE test_reports ENABLE ROW LEVEL SECURITY; ALTER TABLE shipping_checks ENABLE ROW LEVEL SECURITY; ALTER TABLE customer_feedback ENABLE ROW LEVEL SECURITY; ALTER TABLE improvement_suggestions ENABLE ROW LEVEL SECURITY; -- ======================================== -- 创建安全策略（测试阶段 - 允许所有访问） -- ======================================== -- 设备表策略 DROP POLICY IF EXISTS "Enable all for devices" ON devices; CREATE POLICY "Enable all for devices" ON devices FOR ALL USING (true) WITH CHECK (true); -- 组装检测表策略 DROP POLICY IF EXISTS "Enable all for assembly_checks" ON assembly_checks; CREATE POLICY "Enable all for assembly_checks" ON assembly_checks FOR ALL USING (true) WITH CHECK (true); -- 测试报告表策略 DROP POLICY IF EXISTS "Enable all for test_reports" ON test_reports; CREATE POLICY "Enable all for test_reports" ON test_reports FOR ALL USING (true) WITH CHECK (true); -- 发货清点表策略 DROP POLICY IF EXISTS "Enable all for shipping_checks" ON shipping_checks; CREATE POLICY "Enable all for shipping_checks" ON shipping_checks FOR ALL USING (true) WITH CHECK (true); -- 客户反馈表策略 DROP POLICY IF EXISTS "Enable all for customer_feedback" ON customer_feedback; CREATE POLICY "Enable all for customer_feedback" ON customer_feedback FOR ALL USING (true) WITH CHECK (true); -- 改进建议表策略 DROP POLICY IF EXISTS "Enable all for improvement_suggestions" ON improvement_suggestions; CREATE POLICY "Enable all for improvement_suggestions" ON improvement_suggestions FOR ALL USING (true) WITH CHECK (true); -- ======================================== -- 创建索引以提高查询性能 -- ======================================== CREATE INDEX IF NOT EXISTS idx_devices_device_number ON devices(device_number); CREATE INDEX IF NOT EXISTS idx_devices_status ON devices(status); CREATE INDEX IF NOT EXISTS idx_assembly_checks_device_id ON assembly_checks(device_id); CREATE INDEX IF NOT EXISTS idx_test_reports_device_id ON test_reports(device_id); CREATE INDEX IF NOT EXISTS idx_shipping_checks_device_id ON shipping_checks(device_id); CREATE INDEX IF NOT EXISTS idx_customer_feedback_device_id ON customer_feedback(device_id); CREATE INDEX IF NOT EXISTS idx_improvement_suggestions_device_id ON improvement_suggestions(device_id); -- ======================================== -- 插入测试数据 -- ======================================== -- 设备 1 INSERT INTO devices (device_number, model, customer, order_number, status) VALUES ('CNC-2024-001', 'XK7132', '华东机械制造有限公司', 'ORDER-2024-001', 'assembling') ON CONFLICT (device_number) DO NOTHING; -- 设备 2 INSERT INTO devices (device_number, model, customer, order_number, status) VALUES ('CNC-2024-002', 'XK7140', '北方精密仪器厂', 'ORDER-2024-002', 'testing') ON CONFLICT (device_number) DO NOTHING; -- 设备 3 INSERT INTO devices (device_number, model, customer, order_number, status) VALUES ('CNC-2024-003', 'XK7132', '南方汽车零部件公司', 'ORDER-2024-003', 'shipping') ON CONFLICT (device_number) DO NOTHING; -- ======================================== -- 完成 -- ======================================== -- 显示创建的表 SELECT table_name, (SELECT COUNT(*) FROM information_schema.columns WHERE table_name = t.table_name) as column_count FROM information_schema.tables t WHERE t.table_schema = 'public' AND t.table_name IN ('devices', 'assembly_checks', 'test_reports', 'shipping_checks', 'customer_feedback', 'improvement_suggestions') ORDER BY table_name;

5 粘贴并执行 SQL

在 Supabase SQL Editor 中，将复制的 SQL 脚本粘贴到编辑器中，然后点击右下角的 Run 按钮执行。

执行成功后，您会看到结果表格显示 6 个表及其列数。

6 验证数据库

执行完成后，点击左侧菜单的 Table Editor，您应该能看到以下 6 个表：

  • devices（设备表）
  • assembly_checks（组装检测表）
  • test_reports（测试报告表）
  • shipping_checks（发货清点表）
  • customer_feedback（客户反馈表）
  • improvement_suggestions（改进建议表）

点击 devices 表，您应该能看到 3 条测试数据。

7 测试系统

数据库初始化完成后，点击下方按钮打开品控系统：

打开品控系统

您现在应该能够看到 3 个设备了！

✅ 完成！

恭喜！数据库初始化完成。现在您可以开始使用品控系统了。

如果遇到任何问题，请检查浏览器控制台（按 F12）查看错误信息。

💡 提示

如果以后需要重置数据库，可以重新执行这个 SQL 脚本。脚本使用 IF NOT EXISTS 和 ON CONFLICT 语法，可以安全地重复执行。

# 静态版本使用说明

## 📖 简介

这是一个纯静态的 HTML 版本，无需安装任何依赖，直接在浏览器中打开即可使用。

## 🚀 快速开始

### 方法一：直接打开（推荐）

1. 找到 `static` 文件夹
2. 双击 `index.html` 文件
3. 系统会在默认浏览器中打开

### 方法二：通过浏览器打开

1. 打开浏览器（Chrome、Firefox、Safari、Edge 等）
2. 按 `Ctrl + O`（Windows）或 `Cmd + O`（Mac）
3. 选择 `static/index.html` 文件
4. 点击打开

## ✨ 功能特点

### 完整功能支持
- ✅ 设备管理（创建、查看、状态流转）
- ✅ 组装质量检测（记录、照片上传模拟、状态判定）
- ✅ 打样测试（测试报告、逐项确认）
- ✅ 发货前清点（刀具、附件数量核对）
- ✅ 客户追踪（设备编号查询）
- ✅ 持续改进（反馈收集、建议管理）

### 数据存储
- 数据保存在浏览器的 localStorage 中
- 刷新页面数据不会丢失
- 清除浏览器缓存会删除所有数据

### 预置测试数据
首次打开会自动加载 3 台设备的测试数据，方便快速体验功能。

## 📋 使用流程

### 1. 查看设备列表
- 页面加载后自动显示所有设备
- 每台设备显示：编号、型号、客户、订单号、状态

### 2. 创建新设备
- 点击"新建设备"按钮
- 填写设备信息：
  - 设备编号（唯一）
  - 型号
  - 客户名称
  - 订单号
- 点击"创建"

### 3. 查看设备详情
- 点击设备的"查看"按钮
- 进入设备详情页面

### 4. 组装质量检测
- 在设备详情页面，选择"组装检测"标签
- 点击"添加检测项"
- 填写：
  - 检测项目（如：主轴安装精度）
  - 描述（详细说明检测要求）
  - 检测员姓名
- 提交后，点击"合格"或"不合格"进行判定

### 5. 打样测试
- 选择"打样测试"标签
- 点击"添加测试项"
- 填写：
  - 测试项目（如：定位精度测试）
  - 检测标准（如：±0.01mm）
  - 测试结果（通过/不通过）
  - 测试员姓名
- 提交后，点击"确认"按钮进行逐项确认
- 确认时选择"确定"或"取消"

### 6. 发货前清点
- 选择"发货清点"标签
- 查看统计信息（总项目数、已清点、数量一致）
- 点击"添加清点项"
- 填写：
  - 项目名称（如：φ10mm立铣刀）
  - 类型（刀具/附件/其他）
  - 要求数量
  - 清点员姓名
- 点击"清点"按钮，输入实际数量并确认状态

### 7. 状态流转
- 组装中 → 测试中：所有检测项完成后，点击"完成组装"
- 测试中 → 待发货：所有测试项确认通过后，点击"完成测试"
- 待发货 → 已发货：所有清点项数量一致后，点击"确认发货"

### 8. 客户追踪
- 点击顶部导航"客户追踪"
- 输入设备编号（如：CNC-2024-001）
- 点击"查询"
- 查看设备信息和完整品控记录

### 9. 提交反馈
- 在客户追踪页面，选择"客户反馈"标签
- 点击"提交反馈"
- 填写：
  - 反馈类型（质量问题/性能问题/服务问题/改进建议）
  - 评分（1-5星）
  - 详细描述
  - 您的姓名
- 点击"提交"

### 10. 添加改进建议
- 在客户追踪页面，选择"持续改进"标签
- 点击"添加改进建议"
- 填写：
  - 改进建议内容
  - 优先级（高/中/低）
- 点击"提交"
- 可以标记建议状态（待处理→处理中→已完成）

## ⚠️ 注意事项

1. **数据存储**：所有数据保存在浏览器本地，清除缓存会丢失数据
2. **照片上传**：静态版本模拟了照片上传功能，实际不保存图片文件
3. **设备编号**：创建设备时请确保设备编号唯一
4. **浏览器兼容**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）

## 🔄 数据管理

### 清除所有数据
如果需要重新开始，可以：
1. 打开浏览器开发者工具（F12）
2. 进入 Application/Storage 标签
3. 找到 Local Storage
4. 删除 `qcDevices` 项
5. 刷新页面，系统会重新加载测试数据

### 导出数据
可以在浏览器控制台执行：
```javascript
console.log(JSON.parse(localStorage.getItem('qcDevices')))
```

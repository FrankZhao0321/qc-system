🚀 部署到服务器供团队使用

💡 为什么选择 Vercel？

  • ✅ 完全免费
  • ✅ 部署非常简单（一键部署）
  • ✅ 自动 HTTPS（安全加密）
  • ✅ 全球 CDN（访问速度快）
  • ✅ 支持自定义域名

📋 方法一：使用自动部署脚本（推荐，最简单）

1 打开终端

在 Mac 上，按 Cmd + Space，输入 "Terminal" 并打开

2 进入项目目录

在终端中运行：

cd /Users/frank/Documents/trae_projects/QC/static

3 运行部署脚本

在终端中运行：

./deploy.sh

脚本会自动完成所有部署步骤！

4 等待部署完成

脚本会：

  • 检查并安装必要的工具
  • 引导您登录 Vercel
  • 自动部署项目
  • 显示访问 URL

5 分享给团队

部署完成后，脚本会显示一个 URL，例如：

https://qc-system.vercel.app

将这个链接分享给团队成员，他们就可以通过手机或电脑访问了！

📋 方法二：手动部署（需要更多操作）

1 安装 Node.js

访问 https://nodejs.org/ 下载并安装 LTS 版本

2 安装 Vercel CLI

在终端运行：

npm install -g vercel

3 登录 Vercel

在终端运行：

vercel login

按照提示输入邮箱并验证

4 部署项目

在项目目录运行：

vercel --prod

📱 部署后如何使用

✅ 部署成功后：

  • 团队成员只需在浏览器中打开部署的 URL
  • 所有数据都存储在 Supabase 云数据库中
  • 数据会实时同步，多人同时使用也没问题
  • 支持手机、平板、电脑访问

🔧 更新系统

如果需要修改系统：

  1. 修改本地文件
  2. 在项目目录运行：vercel --prod
  3. 等待几分钟，更新就会生效

❓ 常见问题

Q: 部署后看不到设备？

A: 确保数据库表已经创建。在 Supabase SQL Editor 中执行 database.sql 脚本。

Q: 部署失败怎么办？

A: 检查终端中的错误信息，确保网络连接正常，Vercel 账号已正确登录。

Q: 可以离线使用吗？

A: 不可以。系统需要连接互联网才能访问 Supabase 数据库。

Q: 数据会丢失吗？

A: 不会。Supabase 会自动备份数据，但建议定期导出重要数据。
